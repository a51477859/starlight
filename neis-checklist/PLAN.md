## 3. 화면 구성

1. **표지** — 제목, 기준일(2026.6.17. 경기 원문), 진행률(내 체크 n/총 m)
2. **한눈에 보기** — 1~10단계 흐름을 한 줄 동선으로. 단계마다 “어디서 / 무엇을 / 버튼”
3. **나이스 화면 둘러보기** — 목업 위에서 상단바·0단계 메뉴(학급담임)·메뉴트리·탭·조회조건·그리드·버튼 위치 짚기
4. **단계별 따라하기(9장)** — picturebook `tour` 구조:
   - 왼쪽: 번호 단계 목록(클릭하면 그 단계 재생)
   - 오른쪽: 나이스 창 목업 + 가짜 커서가 메뉴를 차례로 누르고, 누를 버튼에 강조 링, 필요한 곳은 확대
   - 아래: 이 단계의 □체크 항목(원문 문구), ※주의는 별도 메모 톤
5. **자주 틀리는 곳** — 비고 vs 출결특기사항, 동아리 비연동, 수정 후 재반영 순서, 1학기 학생부 마감 금지
6. **도구** — 나이스 바이트 계산기(자율동아리 90바이트 확인), 체크 진행 저장(localStorage), 인쇄
7. **부록** — 기재요령 변천표, 출처

## 4. 기술 설계

- **목업 엔진**: picturebook의 `data-spec`(요소 % 좌표) + `steps`(`show/hide/hl/tap/move/type/cam`) 방식을 나이스용으로 새로 작성. 장면 정의는 `scenes.js`에 JS 객체로(로컬 file://에서 JSON fetch 불가 회피)
- 나이스 목업은 **이미지가 아니라 HTML/CSS로 다시 그림** → 확대해도 선명, 문구 수정 쉬움, 학생 정보는 가상
- 모션: transform/opacity만, ease-out 한 종류, `prefers-reduced-motion`이면 커서 애니메이션 대신 정지 컷
- 글꼴: Pretendard(로컬 woff2) + 숫자·메뉴경로는 고정폭

## 5. 디자인 방향(unslop 기준)

- 세계관: **교무실 업무 서류 + 나이스 포털**. 종이 톤 배경, 먹색 글자, 포인트 1색(나이스 파랑 계열)은 “지금 누를 곳”에만
- 금지: 보라 그라데이션, 글로우, 이모지 아이콘, 느낌표, 굵은 800+ 제목, 대문자 라벨, 둥둥 떠다니는 장식, 모든 카드 같은 크기
- 체크 표시, □/※ 기호 등 원문 공문의 기호 체계를 그대로 살려서 “선생님이 아는 문서”처럼
- 크레딧: 원문 출처(경기도교육청 연수물, “단순참고용” 문구 유지), unslop by @heydamir(CC BY 4.0)

## 7. 방향 확정(프로토타입 v0.1)

- **보드 = 그룹 메모지**: 할 일을 13장의 메모지(그룹)로 묶고 4칸(기초 자료 / 학생생활 / 성적 / 반영 · 마감)에 붙임. 메모지 안에서 항목을 하나씩 체크
- **다 체크하면 귀퉁이가 들림 → 당기거나 눌러서 떼기** → 오른쪽 **완료한 작업** 목록으로 이동(뗀 시각, 항목 펼쳐 보기, 다시 붙이기, 되돌리기 토스트)
- 메모지 제목이나 ⋯ → 오른쪽 시트에 원문 상세(경로, {버튼}은 키캡, ※ 주의). 나중에 여기에 나이스 화면 따라하기가 들어감
- 참고: 핀터레스트 칸반(파스텔 카드, 점 진행률, 동그라미 체크) + jaehee-archive(굵은 먹색 칸 머리줄, Pretendard, 숫자 tabular)
- unslop 검수: 이모지 0, 느낌표 0, 그라데이션은 귀퉁이 종이 접힘에만, 굵기 400/500, 색 = 영역 의미만, 모션은 transform/opacity + 한 가지 ease, reduced-motion 대응, 다크 모드
- 로컬 저장(localStorage), 인쇄 시 A4 □ 체크리스트로 바뀜, 바이트 계산기(90바이트 기준)
